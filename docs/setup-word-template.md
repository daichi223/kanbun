# Word テンプレート（.dotm）セットアップ手順

KBR Editor で出力した Word ドキュメントで返り点を自動整形するため、マクロ有効テンプレート（.dotm）を作成します。

## 前提条件

- Microsoft Word（Windows/Mac）
- マクロ機能が有効であること

## セットアップ手順

### 1. 新しいテンプレートを作成

1. Word を起動
2. **ファイル** → **新規** → **白紙の文書**
3. **ファイル** → **名前を付けて保存**
   - ファイル名: `KanbunTemplate.dotm`
   - ファイルの種類: **Word マクロ有効テンプレート (*.dotm)**
   - 保存場所: Word のテンプレートフォルダ
     - Windows: `%APPDATA%\Microsoft\Templates`
     - Mac: `~/Library/Group Containers/UBF8T346G9.Office/User Content/Templates`

### 2. VBA マクロを追加

1. **Alt + F11**（Mac: **Option + F11**）で VBA エディタを開く
2. 左側のプロジェクトエクスプローラーで `KanbunTemplate.dotm` を選択
3. **挿入** → **標準モジュール** を選択
4. `docs/KanbunTemplate.bas` の内容をコピーして貼り付け
5. **ファイル** → **保存** で保存
6. VBA エディタを閉じる

### 3. テンプレートを保存

1. 通常の Word 画面に戻る
2. **ファイル** → **名前を付けて保存** で再度保存
3. マクロが保存されたことを確認
4. Word を閉じる

### 4. 動作確認

1. KBR Editor で漢文ドキュメントを作成
2. 返り点を追加（Alt+1-9）
3. **Word出力** ボタンで .docx を出力
4. 出力された .docx ファイルを Word で開く
5. マクロが自動実行され、`{KAI:レ}` などのトークンが整形される
6. 「返り点の整形が完了しました」というメッセージが表示される

## パラメータ調整

返り点の位置やサイズが適切でない場合、VBA コードのパラメータを調整します。

### 調整可能なパラメータ

```vba
Const KAI_FONT_SIZE As Single = 8        ' 返り点のフォントサイズ（pt）
Const KAI_SCALING   As Integer = 60      ' 文字の縮尺（%）
Const KAI_POSITION  As Single = -1.8     ' ベースライン移動（pt、負で下方向）
Const KAI_SPACING   As Single = -0.3     ' 文字間隔（pt、負で詰める）
Const KAI_FONT_NAME As String = "游明朝" ' フォント名
```

### 調整の指針

| 問題 | 調整方法 |
|------|---------|
| 返り点の位置が**高すぎる** | `KAI_POSITION` を `-2.0` ～ `-2.2` へ |
| 返り点の位置が**低すぎる** | `KAI_POSITION` を `-1.5` ～ `-1.6` へ |
| 返り点が**大きすぎる** | `KAI_SCALING` を `55` ～ `50` へ |
| 返り点が**小さすぎる** | `KAI_SCALING` を `65` ～ `70` へ |
| ベース文字と**離れすぎ** | `KAI_SPACING` を `-0.4` へ |
| ベース文字と**重なる** | `KAI_SPACING` を `-0.2` へ |

### パラメータ変更手順

1. Word で `KanbunTemplate.dotm` を開く
2. **Alt + F11** で VBA エディタを開く
3. モジュール内のパラメータを編集
4. 保存して閉じる
5. テスト用の .docx を再度開いて確認

## トラブルシューティング

### マクロが実行されない

1. **ファイル** → **オプション** → **セキュリティ センター** → **セキュリティ センターの設定**
2. **マクロの設定** で「警告を表示してすべてのマクロを無効にする」または「デジタル署名されたマクロを除きすべてのマクロを無効にする」を選択
3. ドキュメントを開く際に「コンテンツの有効化」をクリック

### {KAI:} トークンが残ったまま

- マクロが正常に実行されていません
- VBA エディタで `FormatKaeritenV3` を手動実行（F5）してエラーを確認

### 返り点の位置がおかしい

- 縦書き設定を確認: **レイアウト** → **文字列の方向** → **縦書き**
- 文書のグリッド設定: **レイアウト** → **ページ設定** → **文字数と行数** タブ → **文字数と行数を指定する** をオフ

## フォント推奨設定

返り点の位置精度は使用フォントに依存します。以下のフォントを推奨：

- **游明朝**（デフォルト）
- **源ノ明朝**
- **ヒラギノ明朝 ProN**
- **MS 明朝**

フォントを変更する場合、`KAI_FONT_NAME` とドキュメントの基本フォントを統一してください。
